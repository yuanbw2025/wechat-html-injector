云中书网页剪存

安装完成后，先完成下面配置，之后在任意网页右下角点击“剪存网页”，或使用右键菜单/快捷键剪存到 WPS。

1. 安装并登录 WPS CLI

本地组件使用 WPS 官方 CLI 写入云文档。请先安装 kdocs-cli，然后在终端运行 kdocs-cli auth login。登录凭据由 CLI 保存到系统密钥链。

2. 安装本地剪存组件

下载本扩展发布包中的 native-host 目录，复制并填写 host-manifest.example.json，再运行对应系统安装脚本。Chrome 不允许扩展静默安装本机程序，因此这一步需要用户主动执行一次。

3. 配置 WPS 目标目录

填写一个你有编辑权限的 WPS 文件夹或知识库目录链接。插件会把每篇网页创建成独立的智能文档。

4. 配置网页总结 API（可选）

网页总结沿用公众号编辑器里保存的 API 配置。未配置时网页剪存仍可用，但“网页总结”会提示先填写 API。

安全说明

组件只在剪存时启动，通过 Chrome Native Messaging 通信，不开放公网端口，不执行任意命令，空闲 5 分钟后自动退出。网页内容和凭据不会发送到本项目远程服务器。
