云中书网页剪存

安装完成后，先完成下面配置，之后在任意网页右下角点击“剪存网页”，或使用右键菜单/快捷键剪存到 WPS。司南首页已内置在插件中，不需要访问国外静态网站。

1. 一键安装 WPS 剪存组件

不用找目录、不用复制 JSON、不用手动安装命令行。选择你的系统，下载后运行安装器；安装器会自动安装必要程序、注册浏览器组件，并打开 WPS 登录。

macOS：双击下载的 `.pkg` 安装包，按系统安装器提示完成；若系统首次拦截，请右键文件选择“打开”。Windows：右键下载的 .ps1 文件，选择“使用 PowerShell 运行”。Linux：在文件管理器中右键脚本，选择“运行”，或交给系统的终端打开。

3. 配置 WPS 目标目录

填写一个你有编辑权限的 WPS 文件夹或知识库目录链接。首次剪存时插件会在这里自动创建“网页剪存”文件夹，之后每篇网页都会作为独立智能文档保存在这个文件夹中。

4. 配置网页总结 API（可选）

网页总结沿用公众号编辑器里保存的 API 配置。未配置时网页剪存仍可用，但“网页总结”会提示先填写 API。

安全说明

组件只在剪存时启动，通过 Chrome Native Messaging 通信，不开放公网端口，不执行任意命令，空闲 5 分钟后自动退出。网页内容和凭据不会发送到本项目远程服务器。
