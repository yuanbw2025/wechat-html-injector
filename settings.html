云中书插件设置

首页、WPS 剪存和 AI 总结都在这里配置。

新标签页

默认打开内置司南；也可以跳转到自定义网址。

浏览器主页

主页按钮可以使用司南，也可以设置成与新标签页不同的网址。

Chrome/Edge 要求用户在主页设置里粘贴确认一次；新标签页则由扩展直接接管。如果新标签页仍显示 Google/Bing，请停用其他新标签页扩展。

安装或修复本地组件

安装器会自动配置 WPS CLI 和浏览器通信组件。已经安装过也可以直接覆盖修复。

WPS 保存目录

填写有编辑权限的 WPS 文件夹或知识库目录。插件会在其中创建“网页剪存”文件夹。

网页总结 API

API Key 只保存在本机。点击网页总结后，当前网页正文会发送到所选 AI 服务。
