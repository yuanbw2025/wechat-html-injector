# 微信公众号 HTML 插入器

> 配合 **[云中书 YunType](https://yuntype.pages.dev)** 排版工具使用 —— 在微信公众号编辑器中一键插入精美 HTML 排版，告别平淡无奇的公众号样式。

---

## ✨ 功能特性（v5.0.2 AI 工作台版）

- **常驻原生左栏**：优先挂载到公众号编辑页 `#js_mp_sidemenu` / `#js_side_article_list`，打开页面即出现在左侧，不再是弹窗式工作台
- **单一 HTML 编辑区**：粘贴 HTML 后自动渲染到公众号原生编辑区；在原生编辑区改内容/格式后，HTML 编辑区自动回读最新 DOM
- **护眼阅读背景**：提供默认白、竹影清风、青野孤舟、牛皮纸黄、素纸生宣、星雪澄霄等小说阅读器风格浅色背景皮肤，含竹叶、山水、水波、纸纹等淡纹理，只改变编辑时看到的页面，不写入正文 HTML
- **紧凑竖向导航**：样式 / 护眼 / HTML / 图片 / AI 配置放在最左侧竖栏，样式页内用顶部二级标签切换骨架、配色、字体
- **样式模板保存**：在样式页保存当前骨架 / 配色 / 字体组合，后续可一键复用
- **页面化 AI 配置**：内置 OpenAI、豆包（火山方舟）、Agnes 和自定义 OpenAI-compatible 配置，支持一键测试连接；豆包使用完整 `/api/v3/chat/completions` 地址和 `ep-...` 推理接入点 ID
- **多 API 配置**：支持把不同服务商和模型保存为本机 API 档案，按任务加载切换；测试连接会显示绿色成功状态或红色错误日志
- **本地知识库**：在浏览器 IndexedDB 保存排版格式、常用指令和参考文档，聊天时按关键词检索相关内容作为上下文
- **AI 对话工作台**：围绕当前正文多轮对话，AI 返回可确认的整篇替换或片段插入操作，支持撤销
- **图片与文件附件**：支持本地图片、剪贴板截图、TXT/Markdown/JSON/CSV/HTML、基础 PDF 文本和 DOCX 正文提取
- **🖼 图片库（解决 HTML 内插图难题）**：扫描文章里已上传的图片（合法的微信 CDN 链接），点缩略图即把 `<img src="…">` 插到光标处，想放哪放哪、随意排版，发布不会丢图
- **模板片段**：内置常用卡片/引用/按钮等，可保存自定义模板
- **可拖拽改宽 + 快捷键**：面板宽度可拖动调整，`Alt+H` 一键开关
- **代码安全过滤**：自动剥离 `<script>` / `<iframe>` / 事件处理器等危险标签

## 🚀 快速上手

### 第一步：安装插件

**Chrome 浏览器**

1. 下载本仓库（点右上角 `Code → Download ZIP`，解压）
2. 地址栏输入 `chrome://extensions/` 回车
3. 右上角开启 **开发者模式**
4. 点击 **加载已解压的扩展程序**，选择解压后的文件夹
5. 安装完成 ✅

**Edge 浏览器**

1. 同上解压，地址栏输入 `edge://extensions/` 回车
2. 左下角开启 **开发人员模式**
3. 点击 **加载解压缩的扩展**，选择文件夹
4. 安装完成 ✅

---

### 第二步：用云中书生成排版 HTML

1. 打开 **[云中书 YunType](https://yuntype.pages.dev)**
2. 左侧粘贴 Markdown 内容，右侧选择配色 / 字体 / 比例
3. 点击 **导出 HTML**，复制生成的代码

> 云中书支持小红书风格多图排版、微信公众号长图文、信息图等多种格式。

---

### 第三步：在公众号编辑器里编辑 HTML

1. 用安装了插件的浏览器打开微信公众号后台，新建图文
2. 云中书工作台会自动出现在公众号编辑页左侧原生栏；如果微信页面结构变了，才会退回 **`</> HTML` 边缘标记**（也可按 `Alt+H`）
3. 切到 **HTML**，直接粘贴排版代码；插件会自动写入公众号原生编辑区并显示效果。也可以切到 **知识** 保存常用排版规范和指令
4. 需要微调时，直接在公众号原生编辑区改内容或格式；HTML 编辑区会自动读取最新结果
5. 也可以继续改 HTML，改完会再次自动同步到原生编辑区
6. 眼睛累时切到 **护眼**，选择护眼绿、羊皮纸、浅青等阅读背景；当前选择会本地记住并自动应用。需要保存排版组合时，到 **样式** 页点 **保存样式**
7. AI 调整和 API Key 到 **AI 配置** 页里统一设置；需要连续讨论时切到 **对话**，可附加截图、图片或本地文件

### 关于图片 🖼

微信只认它自己 CDN 上的图片（外链图发布会被清掉），所以图片要先经过微信上传：

1. 用公众号顶部菜单的 **「图片」** 按钮，把要用的图先传进文章（堆在哪都行）
2. 打开本插件面板 → 点 **「图片」**，文章里的图就列成缩略图
3. 把光标放到代码里想要的位置，**点缩略图** —— 自动插入带真实微信链接的 `<img>` 标签
4. 应用后，图片就精确落在你 HTML 设计的位置上，发布也不会丢

## 🔧 技术原理

微信公众号编辑器基于 **ProseMirror**，内容承载在 `.ProseMirror` 这个 `contenteditable` 元素里。

**双向源码**：
- **读**：`editor.innerHTML` 直接取出文章当前的真实 HTML（含已上传图片的 `mmbiz` CDN 链接）
- **写**：HTML 编辑区输入防抖后执行 `editor.innerHTML = 新代码` + 派发 `input` 事件，让 ProseMirror 接管；并清理其规范化时可能多出的空首行
- **防循环**：插件主动写回时用 `state.applying`，程序同步源码框时用 `state.syncingCode`，避免 HTML 与原生编辑区互相递归触发

**图片为什么可靠**：插件不去逆向微信的上传接口（易随版本失效），而是直接扫描 `editor.querySelectorAll('img')` 拿到文章里**已经合法**的 CDN 链接，再交给你在 HTML 里引用。上传走微信原生流程，链接天然有效、发布不被清除。

**安全**：应用前用正则剥离 `<script>` / `<iframe>` / `<object>` / `onXxx` 事件处理器；预览用 `sandbox` 隔离的 iframe 渲染。

## ⚠️ 注意事项

- 本插件以**开发者模式**加载，属于本地扩展，不会上传到 Chrome 商店；常规编辑数据保存在本机。只有主动使用 AI 调整时，当前正文会发送到你配置的 API Endpoint，请确认服务商的数据处理政策
- 知识库和聊天文字保存在本机；只有点击发送后，当前对话上下文、检索到的知识和附件才会发送到你配置的 AI Endpoint
- 图片会作为视觉输入发送；PDF/DOCX 先在浏览器提取文本，扫描型 PDF 或复杂文档可能无法完整识别
- 微信公众号保存发布后，部分复杂 CSS 可能被服务器端二次过滤，建议使用云中书的**内联样式**导出版本
- 仅支持 `https://mp.weixin.qq.com` 域名下的编辑器页面
